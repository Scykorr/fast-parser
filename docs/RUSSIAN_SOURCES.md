## Первая лига

Сайт ФНЛ сам использует публичный сервис `https://fnl-app.fnl.pro`:
`/api/v1/info/activeSeason?leagueId=100` и
`/api/v1/center/calendar/matches/date` с leagueId=100, обнаруженным seasonId,
limit=10, offset, move=ALL, mouth (именно такое имя параметра) и year.
Эти адреса и leagueId найдены в публичном JavaScript сайта, не угаданы.
Ключи, авторизация и платный доступ не требуются. robots сайта разрешает обход;
API robots возвращает 404. Это не дает права на произвольную перепубликацию контента.
В карточке сохранена ссылка на официальный матч-центр, новости, видео, ставки,
контакты и прочие поля не сохраняются.

Даты сервиса без offset трактуются как Europe/Moscow: это явно задано функцией
форматирования официального сайта. В приложение передается UTC. Дата без времени
и 00:00 означают неизвестное точное начало; отображается scheduled_date и пометка
«время уточняется». estimatedDate/estimatedDateTo могут задавать диапазон тура;
их нельзя превращать в выдуманное время одного матча. Явная date имеет приоритет
над estimatedDate: найден завершенный перенесенный матч с различающимися датами.

FUTURE → scheduled, END → finished; будущие нули счета скрываются.
BEGIN вместе с START_FIRST_HALF/END_FIRST_HALF/START_SECOND_HALF дает live/paused
и тайм. Простая цифровая matchTimeStr/matchTime передается как последняя минута,
не непрерывный таймер; неизвестные фазы/форматы минуты не угадываются.
Live-схема подтверждена публичными enum/кодом сайта и синтетическими тестами,
эксплуатационная проверка на реальном идущем матче еще нужна.
Финал требует счета обеих команд; точное окончание отсутствует, действует существующее
72-часовое хранение с first_observed_finished_at, без выдуманного окончания +90 минут.

Активный сезон кешируется 24 часа. План месяцев/offset/увиденных ID сохраняется в SQLite.
Импорт ограничен настроенным окном и ранее незавершенными матчами; неизвестная дата
без единственного дня не импортируется как матч во всем окне. Старые незавершенные
матчи с точным началом добавляют свой месяц к обходу. Повторы ID между страницами,
неполная страница или чужая лига/сезон/месяц открывают карантин, сохраняя удачные данные.
Общая квота ФНЛ — 30 секунд, независимая задача worker; длинное окно загружается постепенно.

## РПЛ: ограничение и дальнейшая работа

06.10.2026 публичная страница РПЛ перенаправила на showcaptcha.
Автоматическая проверка остановлена; решения CAPTCHA, подмены клиента или прокси нет.
Проверен альтернативный официальный РФС: доступные страницы РПЛ заканчиваются сезоном
2023/2024 и не подходят для текущего календаря. Страница UEFA вернула HTTP 403.
Старые данные и неофициальные источники не выданы за текущую РПЛ.

В API у РПЛ collection_supported=false, collection_allowed=false и collection_reason.
Web UI явно показывает «Сбор недоступен», причину и отключает кнопку запуска сбора.
Источник rpl_official в диагностике заблокирован; ручной reset не обещает отсутствующий
адаптер. Worker/CLI не выполняют повторных запросов к этому сайту.
Следующий шаг: доступный официальный публичный контракт текущих матчей, проверка сезона,
статусов/дат/счета и адаптер с тестами. Только после этого включать сбор РПЛ.
