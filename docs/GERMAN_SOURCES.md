# Германия: официальные бесплатные источники — 0.12.0

Дата проверки: 06.10.2026. Две новые официальные записи доступны в стране «Германия».

| Лига | ID текущего сезона | Публичная страница |
|---|---|---|
| Бундеслига | `dfl:bundesliga:2026` | https://www.bundesliga.com/en/bundesliga/matchday |
| Вторая Бундеслига | `dfl:2bundesliga:2026` | https://www.bundesliga.com/en/2bundesliga/matchday |

Один источник `bundesliga_official`, публичный сайт Bundesliga/DFL. Адаптер читает
JSON `ng-state`, уже включенный в HTML. Ключи, платные API и обход блокировок не нужны.
Внутренние Firebase URL из состояния не запрашиваются. Контакты клубов, новости,
изображения и видео не сохраняются. robots.txt проверен: страницы matchday разрешены
для FastParser; это техническая проверка обхода, а не лицензия на перепубликацию данных.
Общий постоянный лимит обеих лиг — минимум 30 секунд между запросами; 403/429 и
изменение схемы обрабатываются существующими блокировкой, backoff и карантином.

## Контракт и сбор

Проверяются competitionId, seasonId/название сезона, номер тура, уникальность ID,
названия обеих команд и явно заданный часовой пояс. Коллекция выбирается по полной
связке лиги, сезона и тура: одна HTML-страница может содержать данные обеих лиг.
`plannedKickOff`/`kickOff` преобразуются в UTC; при `matchDateFixed != true` точное
время не объявляется подтвержденным, остается день Europe/Berlin и «время уточняется».
Сам день также предварительный и может измениться после назначения матча.

Подтверждены PRE_MATCH → scheduled и FINAL_WHISTLE → finished; у завершенного матча
обязателен полный счет. Остальные значения остаются unknown с raw_status и частым
повторным опросом. Live-фазы, минута и тайм требуют проверки на реально идущем матче;
их поддержка пока не заявлена. Точное окончание не вычисляется по длительности игры.
Сохраняется правило 72 часов после известного окончания/первого наблюдения финала.

План текущих и соседних регулярных туров 1–34 сохраняется в SQLite (`german_plan`).
Граница настройки проверяется по матчам; дополнительные туры загружаются последовательно.
План не удаляет незавершенные задания внутри сезона. Кнопка «Проверить источник»
сбрасывает план, сохраняя общий лимит и блокировку источника. Переход сезона автоматически
отбрасывает старый план. Стыковые матчи имеют иной маршрут и в эти две записи не входят.

## Фактические проверки

- Обе текущие страницы HTTP 200: тур 5 Бундеслиги и тур 7 Второй Бундеслиги,
  по 9 предстоящих матчей в каждой; API и web UI показывают названия обеих команд.
- Завершенные туры 4 и 6 соответственно: по 9 результатов успешно разобраны в памяти.
  Старые завершенные матчи не импортированы в рабочую БД и тела страниц не сохранены.
- Автотесты проверяют UTC, чужой сезон/лигу/тур, повторы ID, неверный счет,
  неизвестный статус, нефиксированное время, план и общий лимит запросов.
- Независимая полная сверка сезона и реальный live-прогон еще не выполнены.
  Официальность источника отображается отдельно от пометки верификации покрытия.

Прежние записи OpenLigaDB остаются отдельными неофициальными записями, без объединения
ID и передачи пометок. Новый сбор используется в режиме official_only по умолчанию.
