Дата: **11.10.2026** (Europe/Moscow). Код на момент передачи: **0.13.1**, SQLite **v3**.
Дополнение **13.10.2026**: код **0.13.2**, SQLite **v4**. Список UI по-прежнему 72 часа;

## 1. Зачем существует приложение

Пользователь хотел бесплатный парсер расписаний и результатов футбола с настройкой
временного окна, легким web UI на Python и хранением карточек три дня после окончания.
В UI нужны страна → лига → матч, команды, счет, начало/конец либо статус игры,
желательно минута/тайм при реальных данных. Дополнительно нужен локальный HTTP API,
чтобы другое приложение на том же ПК получало те же матчи.

Затем требование уточнено: основной сбор строго с официальных бесплатных источников;
прежнее покрытие не скрывать, отдельно показывать непроверенность и постепенно
подключать новые лиги/верифицировать пометки. Платные API использовать запрещено.
Переход на Cursor — продолжение существующего продукта, не новое ТЗ на переписывание.

## 2. Фактическая поставка

- Python 3.14.6 на исходной машине; декларативный минимум 3.13, lock dependencies.
- FastAPI + SQLite WAL + самостоятельный async collector + чистый HTML/CSS/JS.
- Windows start.cmd/start.ps1/stop.cmd, graceful shutdown, локальный bind.
- Политика official_only=true по умолчанию, сохраненный legacy каталог отдельно.
- API v1: каталог/матчи/изменения/пометки/настройки/диагностика, Origin+CSRF для записи.
- Срок 72h финалов/отмененных с защитой от продления и старого source update;
  feed изменений с seq/deleted, маркеры истекших ID, nullable неизвестные поля.
- Официальные рабочие: Примера, Сегунда, Premier League, Championship,
  Serie A, Serie B, Bundesliga, 2. Bundesliga, Первая лига ФНЛ.
- РПЛ — зарегистрированная запись без адаптера, с явной недоступностью в UI/API.
- В локальной базе предыдущего прогона было 147 записей; это не гарантированный
  каталог после clone. Чистый startup seed дает 10 официальных записей, 9 рабочих.
- Product tests 06.10.2026: 131 passed; targeted Edge smoke официальных лиг выполнен.
  Повторная проверка документационной передачи описывается в VERIFICATION_REPORT.
- Docker files существуют, Docker/Linux не проверены; 7-дневный пилот не проведен.

Нельзя рекламировать готовую 1.0, мировой охват, полный live или полностью
верифицированные 9 лиг. Официальные адаптеры имеют проверенную выборку/контракт,
пометки полноценного покрытия — отдельная работа.

## 4. Первые действия в новом редакторе

1. Открыть корень, проверить git status/HEAD/remote.
2. Прочитать AGENTS.md, DOCUMENTATION_INDEX, ТЗ и актуальные риски.
3. Выбрать .venv интерпретатор либо пересоздать окружение по lock на новом ПК.
4. Выполнить изолированный check без startup-изменений в рабочей БД.
5. Прочитать ARCHITECTURE и relevant country passport перед изменением адаптера.
6. Посмотреть свежую диагностику уже работающего приложения либо запустить managed serve.
7. Выбрать одну следующую задачу с проверяемым критерием, не делать общий rewrite.

Свежая доступность источников не проверялась этой документационной задачей.
CAPTCHA РПЛ — факт контрольного запроса 06.10.2026 и текущая кодовая блокировка;
проверять повторно можно ограниченно при работе над РПЛ, не обходя защиту.

## 5. Рекомендуемые следующие задачи

### A. Чистая официальная установка и настройки — исправлено в 0.13.1

Исторические shortcuts `bl1/bl2/bl3/pl/la1/ucl/dfb` сохраняются без строк каталога
и включают лигу, только если shortcut уже есть. Другой отсутствующий ID по-прежнему
отклоняется. `official_only` не выключается, discovery не запускается, официальный
сбор не читает этот список. Следующая открытая задача — B, не повтор A.

### B. Воспроизводимый браузерный smoke текущей политики

scripts/test_browser.cjs сейчас требует international Sky matches, начальные строки,
временно меняет verification/settings и пишет screenshot. Нельзя использовать его
как универсальную проверку official_only/чистой установки.

Сделать isolated smoke на поддержанных synthetic/API fixtures либо на специально
подготовленной отдельной БД; оставить ограниченный live smoke отдельной командой.
Не изменять production verification ради успешного теста. Критерии: clean startup,
официальная лига, обе команды, date-only, счет/null, RPL unavailable, XSS textContent,
CSRF, 390px, pagination/more/refresh, no JS errors, cleanup и restore тестовых изменений.

### C. РПЛ: только при доступном официальном контракте

Открытая задача 0.13.2: public organiser/federation текущий season contract.
Сначала ограниченно проверить доступность; при повторном CAPTCHA остановиться.
Старые РФС сезоны/агрегатор не заменяют текущую РПЛ. Если доступно — отдельно
проверить расписание/финалы, timezone, IDs и статусы, добавить parser/worker/CLI/tests.
Удалить unavailable seed/flags только вместе с рабочим подключением. Обновить паспорт
и evidence, не ставить полный verified по первому успешному запросу.
Если недоступно, продолжать A/B/D, а не бессмысленный повтор запросов.

### D. План и диагностика перед недельным пилотом

Открытые задачи старого этапа 0.12.1 перенесены, не закрыты: bounded attempt budget,
точный план всех официальных источников, gap/unresolved, проверка restore/простоя.
Current plan-collection и diagnostics minimum_sweep описывают преимущественно legacy,
не 7 текущих рабочих official source jobs. Показать честные due/квоты/ожидание страницы,
backoff и coverage gap; не смешивать provider publication lag с собственным polling lag.

Критерии: независимый blocked source не мешает другим; новые windows не создают
бесконечных scans; rollover года/сезона/pruning корректны; старые незавершенные/date-only
не теряются; restore не воскрешает истекшие матчи; API cursor recovery документирован.

### E. Порционная верификация вместо новых лиг без проверки

По одной лиге: завершенный/будущий/реальный live, переносы, midnight/TBC, сезон,
зима/летнее время, финальные стадии. ФНЛ live пока подтвержден public JS и synthetic,
не длительным live-run; DFL unknown live фазы пока не маппятся.
Serie B финальные стадии и DFL стыковые матчи не входят в регулярный адаптер.
Не считать общий metadata success проверкой каждого результата.

```text
Сначала прочитай AGENTS.md, docs/CURSOR_HANDOFF.md, docs/DEVELOPER_GUIDE.md,
docs/ARCHITECTURE.md, docs/ROADMAP.md и docs/IMPROVEMENTS_AND_BOTTLENECKS.md.

сохраненный каталог, независимые пометки покрытия, UTC/null и TTL финалов 72 часа.
РПЛ сейчас в каталоге без рабочего parser: не включай флагом и не обходи CAPTCHA.

enabled_leagues сохраняются без shortcuts, неизвестный ID по-прежнему отклоняется.
Следующей задачей сделай воспроизводимый browser smoke текущей политики (раздел B).

```

Для другой следующей задачи заменить последний абзац, сохранив инварианты. Промпт —
предложение для нового запуска, он не является поручением этой документационной
задаче исправлять настройки/включать источник прямо сейчас.
