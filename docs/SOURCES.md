# Источники и фактическое покрытие

Документ: 1.0.0, 06.10.2026. Стоимость данных: 0. Проверено реальными HTTP-ответами; будущая доступность не гарантируется.

## OpenLigaDB

Официальное описание: [сайт](https://www.openligadb.de/), контракт: [репозиторий](https://github.com/OpenLigaDB/OpenLigaDB-Samples). Бесплатный доступ без аутентификации, данные под ODbL; происхождение и ссылки сохраняются.

Используются `/getavailableleagues` и `/getmatchdata/{leagueShortcut}/{leagueSeason}` на `https://api.openligadb.de`. Первая проверка дала 75 футбольных записей после фильтра актуальных сезонов и выбора нового сезона на shortcut. Community-каталог может быть неполным и содержать дубли.

По умолчанию включены bl1, bl2, bl3, pl, la1, ucl, dfb при наличии. Реальные расписания в окне подтверждены у bl1/bl2/bl3/pl/la1. Пустые ucl/dfb в окне не означают отсутствие полного сезона.

Есть названия команд, UTC-начало, итоговый счёт и флаг завершения. Нет точного текущего тайма/минуты, времени конца и authoritative live-статуса. `lastUpdateDateTime` не считается временем конца. Итог принимается по известному явному названию результата; дополнительное время/пенальти не складываются.

Внутренний предел — запрос раз в 12,5 секунды (4,8/мин), общий для каталога и матчей, сохраняется в БД после рестарта. Это не объявленная квота провайдера. Community-результаты не проверены независимо.

## Sky Sports HTML, экспериментальный

Открытая [страница](https://www.skysports.com/football-scores-fixtures), выбор даты: `/football-scores-fixtures/YYYY-MM-DD`. При обследовании проверены [robots.txt](https://www.skysports.com/robots.txt) и ссылки на условия. Путь страниц не запрещён общему User-agent в просмотренном robots.txt; закрытые `/api/` и `/live-score-centre` не используются. Это не универсальное разрешение на распространение базы; перед внешней публикацией нужны актуальные условия. Приложение использует явный User-Agent FastParser и не обходит блокировки.

Метод — HTML-карточки `[data-component-name="ui-sport-match-score"]` со встроенным `data-state`, разбор BeautifulSoup. Без исполнения JavaScript, скрытых API, ключа и изображений. Одна загрузка обновляет все карточки даты.

Реально подтверждены расписание, финальные и текущие счета, явные минуты у части игр и переносы. Полный мировой перечень не подтверждён. Live-флаги читаются явно; тайм не вычисляется из минуты. Точный конец отсутствует. `AET` не позволяет разделить счёт на основное/дополнительное время; подробные поля остаются null.

Дата карточки сверяется с запросом, время интерпретируется как `Europe/London` с DST. В некоторых карточках нет года, он берётся из URL; stale-content с совпадающим днём/месяцем остаётся риском. Изменение часового пояса/HTML потребует обновления адаптера.

Внутренний предел — запрос раз в 20 секунд, желаемый live-интервал общей страницы — 120 секунд. Сегодня имеет приоритет; прочие даты загружаются постепенно. 429 соблюдает Retry-After, 403/CAPTCHA блокируют источник до действия оператора. Карантин содержит причину, полный HTML не хранится постоянно.

## Общие ограничения

ID источников разделены; автоматического сопоставления и резервирования одного матча пока нет. Пользователь может выбрать другой источник, но это не независимое подтверждение записи.

Страны определяются по известным кодам/названиям, не являются достоверным полем каждого API. Неопределённые лиги — «Страна не указана». Для строгого охвата нужен проверяемый справочник и ручные соответствия.

`state=verified` в 0.7.0 означает успешный валидный сбор выборки, а не независимую проверку результата или полноты сезона. Текущий каталог доступен в интерфейсе и `coverage-report`; числа меняются вместе с источниками.
