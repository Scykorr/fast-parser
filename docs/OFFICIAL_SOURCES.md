## Рабочий сбор

Примера и Сегунда собираются с публичного сайта организатора LaLiga:

- https://www.laliga.com/laliga-easports/resultados
- https://www.laliga.com/laliga-hypermotion/resultados
- Правила частоты: https://www.laliga.com/robots.txt (Crawl-delay 30 секунд).

Адаптер `fast_parser/official.py` читает публичный HTML и встроенный JSON только из
`props.pageProps.matches`. Не используются платные API, ключи, скрытые мобильные endpoints
или обход блокировок. Сезон/дивизион/тур и структура данных проверяются до импорта.
ID официальных записей отделены от OpenLigaDB/Sky; последние не исправляют официальный счет.
Матчи предоставляют `source_url`, `official_source`, `source_role`, `raw_status` через API.

План собирает текущий тур обеих лиг и туры возле настроенного окна. Даты тура приблизительны:
план использует запас 7 дней, а карточки фильтруются точно по окну. Список заданий и общий
интервал сохраняются в SQLite; запрос выполняется один за цикл. Текущий тур, уже прочитанный
с основной страницы, не требует немедленного повторного запроса. Дополнительные страницы
загружаются последовательно, поэтому будущие матчи могут появиться не сразу.

Действует 72-часовое хранение завершенных матчей по существующим правилам. Точное окончание,
минуты и таймы не выдумываются. Пока подтверждены только статусы PreMatch и FullTime;
другие сохраняются как unknown с raw_status и проверяются чаще. Реальный live-контракт
должен быть подтвержден отдельно. Официальность не означает полную верификацию парсера.

## Режим источников и прежнее покрытие

`official_only=true` по умолчанию, в том числе для старых настроек без нового поля.
В этом режиме worker и штатный CLI не собирают OpenLigaDB/Sky, а API отклоняет запрос
ручного обновления их лиг. В интерфейсе они остаются в каталоге с явной пометкой отсутствия
официального сбора. Существующие карточки не удаляются при смене политики; у них виден
неофициальный источник и сохраняются обычные правила актуальности/истечения.

Официальные лиги находятся в стране «Испания»: «Примера · LaLiga», «Сегунда · LaLiga».
Они собираются независимо от списка legacy enabled_leagues. Кнопка проверки сбрасывает
официальный план, сохраняя общий cooldown. Оба официальных дивизиона включены вместе.
Настройка official_only может быть снята оператором для дополнительного legacy-сбора;
такие записи явно неофициальны, их ID не смешиваются с официальными, автоматической подмены нет.
Это дополнительный режим, а не выполнение требования официального охвата остальных стран.

Каталог текущего испанского сезона предварительно создается по границе 1 июля, но сбор
подтверждает сезон по ответу организатора. Предварительная запись не получает верификацию.
Новые страны/лиги добавляются порционно только после исследования бесплатного сайта
организатора и реализации проверенного адаптера. Полный мировой официальный охват пока отсутствует.

## Подтвержденные проверки

06.10.2026, реальный прогон Windows/Python 3.14.6: страницы обеих лиг HTTP 200;
локальный API показал 10 карточек Примеры и 7 Сегунды в текущем окне, команды и provenance
заполнены. Сохраненный каталог: 139 записей (137 прежних и 2 официальных).
Edge/Playwright: обе официальные лиги выбираются и показывают карточки/пометки, pageerror=0.
71 автоматический тест: официальный импорт, срок хранения, неизвестный статус,
защита от отсутствующего итогового счета, лимит и запрет legacy-сбора в основном режиме.
Сверка полноты всего сезона и реальный live в этот результат не входят.
