# Италия: Серия A и Серия B

Продукт 0.11.0, 06.10.2026. Источники официальные и бесплатные; основной режим
official_only сохраняется. Остальные лиги каталога не удалены и не получают чужую верификацию.

## Серия A — Lega Serie A

Официальная страница: https://www.legaseriea.it/serie-a/calendario-risultati

В сетевых запросах этой страницы наблюдался публичный сервис
`https://api-sdp.legaseriea.it/v1/serie-a/football`. Без ключа и авторизации прочитаны
список сезонов и matches. Сначала адаптер определяет сезон по официальным seasonName
и competitionId, затем читает матчи его seasonId; ID сезона не фиксируется навсегда.
Кеш списка сезонов — 24 часа, только идентификатор/год, без тела матчей.
Официальный ответ 2026/27 содержит 380 записей; это структурный факт, а не полная верификация.

Проверяются соревнование, сезон каждой карточки, уникальность matchId, команды, UTC-дата
и счет. FINISHED и UPCOMING подтверждены реальными ответами. Другие статусы остаются
unknown с raw_status; live-минуты/таймы и точное окончание не выдумываются. Обязательный
итоговый счет берется из homeScorePush/awayScorePush. Матчи с неподтвержденной командой
или неверной структурой не импортируются частично.

Важно: неизвестное время может приходить как `YYYY-MM-DDZ`, например `2027-01-16Z`,
вместо datetime. Такой формат разрешен только при isUnknownKickOffTime=true. Сохраняется
scheduled_date, kickoff_at=null; полночь не назначается. Даты без времени фильтруются
по календарному окну, чтобы не импортировать все будущие туры за пределами диапазона.
Список текущего окна повторяется по штатным интервалам; ранее сохраненные незавершенные
карточки проверяются даже за пределами нового окна.

ID лиги `sa:serie-a:2026`, матча `sa:2026:<matchId>`. source=seriea_official,
source_url указывает на официальный JSON-запрос. robots.txt сайта Lega Serie A прочитан:
общий Allow / и отдельные исключенные разделы; используемый календарь к ним не относится.
Для публичного сервиса установлен собственный консервативный предел 30 секунд.

## Серия B — Lega B

Официальный календарь: https://www.legab.it/seriebkt/calendario/2026-2027/stagione-regolare

Это server-rendered HTML без платного API. В календаре имеются выбранный тур,
список доступных туров, карточки .matchday-list, полные названия команд и data-match-id.
Адаптер проверяет выбранный сезон/тур и ссылки матчей, уникальность ID, обязательные поля.
Финал определяется сочетанием giocata и Risultato и требует двух числовых счетов;
Ore — будущий матч; другие состояния сохраняются как unknown.

Дата и время берутся из доступной текстовой подписи конкретной карточки. У этой HTML-даты
нет явного UTC-offset: используется Europe/Rome для календаря организатора в Италии.
Летний пример 20:30 календаря соответствует 18:30 другого представления официального
сайта. Переход лето/зима проверен автоматическими тестами (20:30 → 18:30/19:30 UTC);
реальная зимняя выборка еще требует отдельной сверки. Если час не указан, сохраняется
только scheduled_date. Счет и точное время никогда не выводятся из предполагаемой длительности.

Первым загружается текущий тур, затем соседние страницы в обе стороны, пока они
перекрывают заданное окно; промежуток национальных пауз не считается отсутствием лиги.
План сохраняется в SQLite и запрашивает одну страницу за цикл с лимитом 30 секунд.
Карточки фильтруются точно при известном времени, по календарным дням — при неизвестном.
Старые незавершенные карточки перепроверяются в уже сохраненных заданиях текущего сезона.
Плей-офф/плей-аут не подключены: этот адаптер ограничен stagione-regolare.

ID лиги `sb:serie-b:2026`, матча `sb:2026:<data-match-id>`, source=legab_official.
source_url — официальная страница тура. robots.txt Lega B вернул HTTP 404;
опубликованного Crawl-delay из него не получено, используется собственный предел 30 секунд.
Отдельные 307 главной страницы не обходятся: сбор использует проверенный канонический путь
календаря, доступный сразу HTTP 200, и не следует произвольным перенаправлениям.
Текущий список команд содержит 20 клубов; число 19 на пользовательском скриншоте не
фиксируется в коде. Состав берется из данных текущего сезона организатора.

## Общие правила

Независимые задачи пяти официальных организаторов имеют отдельные постоянные квоты;
403/CAPTCHA останавливают соответствующий источник, 429 сохраняет Retry-After.
72-часовое хранение, nullable-окончание и прежняя защита статусов сохранены; схема SQLite v3.
Новые official_source=true и source_role=primary не равны подтвержденной полноте покрытия.
Новые итальянские лиги начинают с «Не верифицировано»; источник не подменяется агрегатором.

На первом реальном запуске Serie A был остановлен собственным карантином парсера из-за
формата YYYY-MM-DDZ. Добавлен разбор даты без времени и отдельный регрессионный тест.
После исправления снят только этот конкретный локальный карантин: проверены source,
state=open, failures=1 и точный текст ошибки; перед новым запросом сохранены 30 секунд.
HTTP-блокировки/лимиты поставщика не снимались. Полные исторические тела ответов не сохранялись.

100 тестов и compileall прошли: сезоны/дубли/команды/счета, финалы/TTL, дата без времени,
календарный фильтр, летняя/зимняя зона и сохранение плана/квоты.
После исправления реальный API версии 0.11.0 показал 10 scheduled-матчей Серии A
и 10 Серии B в текущем окне, все с командами и официальным provenance. Каталог 143
(141 прежняя запись + 2 итальянские). Edge/Playwright: обе лиги выбираются, карточки
и адреса источников видны, pageerror=0; ширина 390 px без горизонтального переполнения.
JS syntax и git diff --check прошли.
Полный сезон, переносы, зимняя реальная выборка и live остаются предметом следующей сверки.

В интерфейсе обновите страницу, выберите «Италия» → «Серия A · Lega Serie A» или
«Серия B · Lega B». При первом запуске Серии A сначала читается сезон, затем матчи через
30 секунд. Серия B заполняет соседние туры постепенно. Адрес и исходный статус видны
в карточке. Отдельная кнопка проверки ставит официальный сбор в очередь, не отменяя квоту.
