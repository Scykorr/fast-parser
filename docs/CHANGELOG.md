# Изменения продукта

## 0.7.0 — 06.10.2026, предварительная версия

- Python-приложение с лёгким web UI, локальным API и фоновым сбором.
- Окружение Python 3.14.6 и зафиксированные зависимости.
- Реальные бесплатные JSON OpenLigaDB и HTML Sky Sports без ключей.
- Страны/лиги/матчи, обе команды, счёт, даты, статусы и nullable-минута/тайм.
- Настройки, SQLite WAL, постоянные лимиты, lease worker, cooldown/circuit breaker, валидация/карантин.
- Хранение 72 часа, очистка пачками и маркеры повторного импорта.
- CLI, локальный запуск, подготовленный Docker, руководство и повторяемые проверки.

Ограничения: SQLite вместо PostgreSQL; без автоматического объединения/резервирования между источниками и гарантии полного мирового/live-покрытия. Семидневный пилот и профиль с ограничением 2 vCPU / 4 GB ещё не выполнены. Версия 1.0 не выпущена.
