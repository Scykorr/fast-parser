# Изменения продукта

## 0.13.0 — 06.10.2026, предварительная версия

- Россия: рабочая Первая лига с бесплатного публичного сервиса официального сайта ФНЛ.
  Московское время подтверждено кодом сайта, сохраненная пагинация по месяцам,
  сезон/команды/счет/даты проверяются, будущие нулевые счета скрыты.
- Явные live-фазы ФНЛ поддержаны по опубликованному контракту сайта; реальный
  эксплуатационный live-прогон еще не выполнен.
- РПЛ добавлена в каталог со сбором, отключенным из-за CAPTCHA и отсутствия адаптера.
  Причина видна в API/UI, ручной sync/reset возвращает 422; fallback на агрегаторы отсутствует.
- collection_supported/collection_reason в API; защита CAPTCHA-редиректа без перехода
  и сохранения challenge-токенов. Прежние записи каталога сохранены, всего 147.
- 131 тест, compileall и Node syntax check успешны. Реальный ФНЛ: 10 матчей
  (1 завершенный, 9 ближайших); Edge smoke/390px прошли. Схема SQLite v3 без миграции.
- Подключение рабочего РПЛ остается открытым: [RUSSIAN_SOURCES.md](RUSSIAN_SOURCES.md).


## 0.12.0 — 06.10.2026, предварительная версия

  завершенные туры проверены без сохранения старых матчей. Web smoke/390px прошли.
- Схема SQLite v3 без миграции. Live/полная сверка/стыковые матчи остаются открытыми.
  [Подробности](GERMAN_SOURCES.md).


## 0.11.0 — 06.10.2026, предварительная версия

- Италия: рабочие официальные адаптеры Lega Serie A (публичный JSON сайта) и Lega B (HTML).
- Serie A: обнаружение seasonId, даты с неизвестным временем YYYY-MM-DDZ, защита сезона/команд/счета.
- Lega B: текущий и соседние туры, сохраненный план, полный текст команд, календарь Europe/Rome.
- scheduled_date: отдельный день при kickoff_at=null, без выдуманного времени; календарный
  фильтр API/UI учитывает такие записи, импорт не захватывает весь будущий сезон.
- Общий реестр официальных источников; CLI, ручная проверка, API/UI и независимый worker
  поддерживают обе итальянские лиги. 30-секундный лимит каждого источника сохранен.
- 100 тестов и compileall прошли; схема v3 без миграции. [ITALIAN_SOURCES.md](ITALIAN_SOURCES.md).
- Реальный сбор: 10 матчей Серии A и 10 Серии B в текущем окне; каталог 143.
  Браузерный smoke и мобильная ширина прошли после исправления формата даты без времени.

- Основное требование: официальный бесплатный организатор как источник рабочих данных.

- 71 тест и реальный сбор обеих лиг, API и браузерный smoke прошли.
- SQLite v3, отдельная миграция схемы не нужна; меняется поведение сбора по умолчанию.
- Ограничения и руководство: [OFFICIAL_SOURCES.md](OFFICIAL_SOURCES.md).

## 0.8.1 — 06.10.2026, предварительная версия

- Добавлен официальный бесплатный контроль Примеры/Сегунды: отдельный повторяемый скрипт,
  проверка сезона/тура, названий команд, времени, статусов и счетов; лимит 30 секунд.
  Это инструмент проверки, рабочий адаптер Сегунды пока не подключен.
- Сетевые ошибки с пустым текстом сохраняют название типа (например ConnectTimeout).
  Проверено 67 тестов; полный реальный прогон не завершен из-за сетевых ограничений.

- Все текущие лиги доступны независимо от верификации. В выпадающем списке, блоке лиги,
  карточке матча и диагностике показаны отдельные пометки покрытия.
- Форма обновления пометки: непроверено/частично/верифицировано, виды данных, выборка,
  основание и замечания. Сохраняется дата изменения; успешный сбор не меняет пометку.
- API `coverage_verification`, `collection_state`, обновление пометки с Origin/CSRF.
- Схема v3; переход с v1/v2 сохраняет каталог/матчи/настройки и создает резервную копию.
- Новый сезон/источник не наследует чужую верификацию; новые лиги остаются непроверенными.
- Порядок постепенной сверки и бесплатного расширения: [COVERAGE_VERIFICATION.md](COVERAGE_VERIFICATION.md).
- Выполнена первая сверка испанских соревнований; четыре частичные пометки с ограничениями,
  отчет [SPANISH_VERIFICATION.md](SPANISH_VERIFICATION.md) и повторяемый скрипт без хранения старых матчей.
- Отсутствие контрольной страницы (404) не приостанавливает основной источник при верификации;
  общие лимиты и защита 403/429/CAPTCHA сохраняются.

## 0.8.0 — 06.10.2026, предварительная версия

- Защита окончательного результата от неподтвержденного отката статуса; исправления не продлевают retention.
- Перепроверка сохраненных незавершенных матчей вне основного окна; список задержек более 24 часов в диагностике.
- Независимые задачи источников, общий таймаут запроса 30 секунд, продление lease во время запросов.
- API актуальности карточки и `/api/v1/changes` с числовым курсором, удалениями и HTTP 410 для истекшего курсора.
- Схема SQLite v2, резервная копия перед миграцией v1, отказ при неизвестной будущей схеме.
- Включение только последнего сезона, уникальные лиги в настройках; сохранение числа загруженных страниц при обновлении UI.
- Руководство интеграции: [API_INTEGRATION.md](API_INTEGRATION.md).

Остаются: подробный план нагрузки на источники, полная сверка покрытия, резервирование,
семидневный пилот и проверка 2 vCPU / 4 GB. Журнал содержит ID, без исторических карточек.

### Управление запуском и остановкой

- Добавлен stop.cmd и CLI stop с выбором порта: корректное завершение сервером по локальному токену, без убийства процессов по имени/порту.
- Повторный запуск на занятом порту не заменяет контрольный файл работающего экземпляра. Руководство обновлено.

## 0.7.0 — 06.10.2026, предварительная версия

- Python-приложение с лёгким web UI, локальным API и фоновым сбором.
- Окружение Python 3.14.6 и зафиксированные зависимости.
- Реальные бесплатные JSON OpenLigaDB и HTML Sky Sports без ключей.
- Страны/лиги/матчи, обе команды, счёт, даты, статусы и nullable-минута/тайм.
- Настройки, SQLite WAL, постоянные лимиты, lease worker, cooldown/circuit breaker, валидация/карантин.
- Хранение 72 часа, очистка пачками и маркеры повторного импорта.
- CLI, локальный запуск, подготовленный Docker, руководство и повторяемые проверки.

Ограничения: SQLite вместо PostgreSQL; без автоматического объединения/резервирования между источниками и гарантии полного мирового/live-покрытия. Семидневный пилот и профиль с ограничением 2 vCPU / 4 GB ещё не выполнены. Версия 1.0 не выпущена.
