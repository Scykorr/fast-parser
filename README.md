# Fast Parser

Бесплатный сбор футбольных расписаний/результатов с лёгким web UI. Python 3.14.6, FastAPI, SQLite WAL. Продукт **0.13.0**, рабочая предварительная версия.

Основное требование — сбор с официальных бесплатных сайтов организаторов. Рабочий адаптер
LaLiga подключен для Примеры и Сегунды; официальный режим включен по умолчанию.
[Политика, фактическое покрытие и ограничения](docs/OFFICIAL_SOURCES.md).

Добавлены официальные бесплатные Premier League и EFL Championship:
[английские источники и проверки](docs/ENGLISH_SOURCES.md).

Италия: официальные бесплатные Серия A и Серия B:
[источники, разбор дат и ограничения](docs/ITALIAN_SOURCES.md).

Весь каталог доступен, а верификация покрытия отмечается отдельно и обновляется по мере
сверки: [порядок проверки и расширения](docs/COVERAGE_VERIFICATION.md). Источники только бесплатные.

Другие программы на том же компьютере могут читать матчи через локальный HTTP API:
[руководство интеграции](docs/API_INTEGRATION.md). Есть сведения об актуальности и журнал изменений/удалений.

## Запуск

Окружение `.venv` уже создано. Запустите **start.cmd**, затем откройте **http://127.0.0.1:8000**. Первое заполнение занимает несколько минут. **stop.cmd** корректно останавливает сервер и встроенный сбор; Ctrl+C также работает.

```powershell
.\.venv\Scripts\python.exe -m fast_parser serve
```

На новом компьютере сначала:

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock
```

Платные API не нужны. OpenLigaDB используется без ключа, Sky Sports — через открытые HTML-страницы. Выберите страну → лигу → матч: обе команды, счёт, начало, статус и доступные live-поля. Настройки доступны через интерфейс, БД — `data/football.sqlite3`.

Матчи скрываются через 72 часа от известного конца или первого наблюдения завершения. Полный мировой охват и точные live-минуты не гарантированы; источники пока не объединяются автоматически.

## Проверки

```powershell
.\scripts\check.ps1
.\.venv\Scripts\python.exe -m scripts.benchmark
```

Браузерный smoke: `node scripts/test_browser.cjs` при доступном Playwright, Edge и работающем сервере; `PLAYWRIGHT_MODULE` задаёт путь к установленному модулю. Границы замеров описаны в отчёте. Docker: `docker compose up --build` (подготовлен, не проверен здесь). Сервер привязан к localhost.

Германия: Бундеслига и Вторая Бундеслига с официального бесплатного сайта Bundesliga/DFL.
[Контракт, проверки и ограничения](docs/GERMAN_SOURCES.md).
